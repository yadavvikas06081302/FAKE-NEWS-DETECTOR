# 📰 Fake News Detector
An AI/ML-based Fake News Detection System that predicts whether a given news article is Real or Fake using Machine Learning techniques.

🚀 Live Demo

🔗 Try the Live Demo:
https://fake-news-detector-ib6gn7um9cmf7hvsihuzam.streamlit.app/

📌 Project Overview

Fake news can spread quickly through social media and online platforms. This project uses Machine Learning and Natural Language Processing (NLP) to analyze news text and classify it as either Real News or Fake News.

The project includes a simple and user-friendly Streamlit web application where users can enter news content and get a prediction.

✨ Features

- 🔍 Fake News Detection
- 🤖 Machine Learning based prediction
- 📝 News text input
- ⚡ Fast prediction
- 🌐 Streamlit web interface
- 📊 NLP-based text processing
- 💻 Easy to use interface

⚙️ Installation

Clone the repository:

git clone https://github.com/yadavvikas06081302/FAKE-NEWS-DETECTOR.git

Go to the project folder:

cd FAKE-NEWS-DETECTOR

Install the required dependencies:

pip install -r requirement.txt

▶️ Run the Application

Start the Streamlit application:

streamlit run app.py

The application will open in your browser.

🎯 How It Works

1. User enters a news article or news statement.
2. The text is processed using NLP techniques.
3. The trained Machine Learning model analyzes the text.
4. The system predicts whether the news is Real or Fake.
5. The prediction is displayed on the Streamlit interface.

📚 Project Files

- app.py – Streamlit web application
- Fake News Detector.ipynb – Fake news detection model/notebook
- Face News Prediction Model.ipynb – News prediction model
- Scam Detection.ipynb – Scam detection notebook
- requirement.txt – Required Python libraries
